# slotnull

Slot validation gates for null inputs before they hit prod.

**Site:** https://theworker02.github.io/slotnull/

## Install / run

```bash
git clone https://github.com/theworker02/slotnull.git
cd slotnull
node src/cli.js
node --test
```
